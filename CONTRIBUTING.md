# Bidrag til HAlarm

Fejlrapporter bør indeholde Home Assistant version, Google/Nest model, firmware hvis kendt og de anonymiserede tilstandsovergange fra **HAlarm → Indstillinger**. Indsæt aldrig adgangstokens, privat IP, personlige lydfiler eller hele `.storage` filen i en offentlig issue.

Ret gerne kode via pull request med en kort beskrivelse og regressionstest. **Stemmestop er heuristisk:** nye overgange skal testes både ved stemmestop og ved naturlig lydafslutning.
