# Udgivelse

Repository: https://github.com/JRJenZens/HAlarm

HAlarm kan tilføjes som et brugerdefineret HACS-repository af typen Integration.
Det er ikke en optagelse i HACS' standardkatalog. Officiel optagelse kræver separat
review, herunder Home Assistant Brands.

Ved næste release: kør testene fra README, opdatér manifestversion, frontendens
cacheversion og changelog, og publicér en GitHub-release med samme versionstag.
Pak kun custom_components/halarm i installationspakken; medtag aldrig .storage,
konfigurationer, tokens eller brugerens MP3-filer.
