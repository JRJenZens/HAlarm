# Sikkerhed

Rapportér sikkerhedsproblemer privat til repository ejer via GitHub, hvis privat rapportering er slået til. Indsæt aldrig tokens eller personlige alarmfiler i offentlige issues.

HAlarm spejler alarm MP3-filer til en statisk HTTP-sti, der kan tilgås uden Home Assistant-login. Læg ikke følsomme optagelser i `sounds/`.
